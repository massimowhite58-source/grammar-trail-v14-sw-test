# Component Library v1.0 — approved architecture

## Three levels
1. Base components — atomic controls and display elements.
2. Composite components — assembled interface patterns.
3. Feedback components — state, result and error messages.

## Groups
Buttons: Primary, Secondary, Tertiary, Icon, Destructive.
Inputs: Text, Password, Search, Textarea.
Selection: Checkbox, Radio, Switch, Select.
Cards: Standard, Interactive, Statistic, Content.
Navigation: Tabs, Breadcrumbs, Pagination.
Overlays: Modal, Dialog, Drawer, Popover.
Feedback: Toast, Alert, Tooltip, Progress Indicator.
States: Loading, Skeleton, Empty, Error, Success.

## Shared states
Default, Hover, Focus, Active, Disabled, Loading, Error. Document mouse, keyboard and touch behavior for each interactive component.

Every component documents purpose, appearance, variants, sizes, states, behavior, responsive rules, accessibility and examples. Components use shared Foundation tokens and support Dark/Light themes.

The architecture is approved; the complete production component set and implementation are not claimed as finished.
