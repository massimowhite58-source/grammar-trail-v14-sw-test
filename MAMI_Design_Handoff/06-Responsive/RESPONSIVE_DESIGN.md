# Responsive Design v1.0

Breakpoints: Mobile 320–767 px; Tablet 768–1023 px; Desktop 1024–1439 px; Large Desktop 1440 px+.

Mobile-first touch interactions; adaptive navigation; responsive grids/cards; readable typography; comfortable touch targets; reduced motion. No layout assumption about a fixed number of content units.

Shell: desktop sidebar 248 px, topbar 68 px, content max 1200 px; tablet collapsed rail 76 px; mobile hidden sidebar, 60 px topbar and fixed bottom navigation.

QA viewports: 320×568; 390×844; 768×1024; 1440×900.
