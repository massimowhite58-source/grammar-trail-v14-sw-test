# MAMI Design Handoff v1.0

Brand: **MAMI — Massimo Mega Intelligence**.

This branch is an isolated visual-handoff review branch, created from `main`. It does not change the production repository or merge into the existing test baseline.

## Approved direction
- Navy + Gold brand palette.
- Dark is the primary theme; Light is the alternative.
- Preserve the approved gold ribbon mark and MAMI wordmark; do not redesign the logo.
- Skills shown in the product: Grammar, Vocabulary, Reading, Writing only.
- The learning engine owns task selection, evaluation, mastery, adaptation and recommendations. The UI only presents engine-provided state.
- No fabricated progress, mastery scores or recommendation explanations.
